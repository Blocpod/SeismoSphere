# Curved observation profiles

Open Earth tools → Section → Curved waypoint profile. Enter 2–32 latitude/longitude pairs, one per line, and choose the corridor half-width in the section form. Consecutive waypoints define minor great-circle arcs, each 50–18,000 km; the total must not exceed 30,000 km. Invalid, coincident and antipodal endpoints are rejected.

Each earthquake is assigned to its nearest bounded arc. Distances use spherical cross-track coordinates and the exact angular distance to clamped endpoints. Rounded endpoint caps are included. Ties within 0.1 mm use the earliest segment. Every observation is included at most once, including near bends and overlapping corridors. The profile's horizontal coordinate is cumulative distance along the path; depth remains the catalog value. Signed offset follows the nearest segment, with endpoint distance included. Reversing a simple path reverses its along-path coordinate.

The Earth switches to true-depth X-ray, hides competing watch/path/field geometry, and displays the yellow selected path with depth-colored projected hypocenters. These are projected observations, not their original cross-track positions. X-ray markers can show through the Earth. Selecting a profile event uses its original observation. Exit curved profile restores prior depth/X-ray and hypothesis visibility; switching to an ordinary globe or planar cutaway clears the curved overlay.

JSON and SVG evidence retain the path, catalog context, cutoff, selected events and projection method. CSV adds zero-based segment index and distance to the path. Figure evidence identifies the curved profile separately from a planar cutaway; figure/video captions identify projected observations. Video context changes retain the existing stop-on-scene-change behavior. Native encoded-video delivery has not been rechecked for this feature.

The depth profile currently contains observations only. It does not project Slab2 contours onto multiple segments, generate a curved clipping solid, infer a subsurface fault surface or supply local crust structure. Bends can juxtapose separated observations after projection. Geological source integration and curved subsurface surfaces remain unfinished parts of the broader goal.

Verification: numerical tests cover dateline crossings, corners, rounded endpoints, reversed direction, radial depth and invalid geometry. Figure evidence preserves the projected subset and snapshot values. The full suite passed 141 tests; subsequent focused checks also cover sonification using only the curved subset. The live Americas path selected 273 observations; a wider Fiji dateline path selected three deep observations whose projected markers were visually checked. At 390-pixel width the dialog has no page overflow. Exit restored depth, field, path and X-ray controls; no browser errors were observed. Browser viewport checks do not establish physical-device acceptance.
