## Requirements versus suggestions

- Brief 2 section 27 calls Unreal the **preferred** engine and lists complementary technologies as **potential**. The required result is the specified Earth presentation and interaction quality. Rewriting the working renderer in Unreal is not independently required.
- Section 31 calls the six field displays **possible render modes**. Scientific presentation and the ability to disable cinematic effects are explicit requirements. Implementing every suggested field mode is not an independent completion gate.
- Section 40 is a **suggested technical stack**. Existing local implementations must satisfy behavior, provenance and reliability; particular database or stream brands are not deliverables by themselves.
- Sections 20, 21, 42 and 52 require honest scoring, comparison, counterevidence and frozen records. Section 52 explicitly says the mission is not to prove the methodology correct. Established earthquake-prediction skill, a favorable model ranking or statistical significance are not conditions for software completion. Unsupported probabilities must remain unavailable; negative or pending evidence must remain visible.
- The user's later direction explicitly permits an illustrative configurable route graph pending canonical source encoding. Do not manufacture canonical corridors. Their later direction also excluded a packaged installer; the desktop shortcut and reliable launcher remain required.
- Physical mobile/XR acceptance and subjective visual superiority remain unverified. Browser viewport results cannot substitute for those checks.

## Swarm measurements (§14)

The earlier engine returned bin count, maximum magnitude and approximate moment only. It now also computes exact pairwise spherical diameter for the retained 20 bins, early-to-late centroid distance/bearing and mean depth difference, and equal-duration-half event rates with signed change. Research exposes values, source IDs and methods. Missing temporal contrast remains unavailable. These are summaries of the existing two-degree bins, not a fitted swarm detector; source moments still assume Mw-equivalence across native magnitude scales. Existing redistribution routing and forecast scores are unchanged. Broader claims about target splitting, causal accumulation, automatic global concentric discovery and full graph-topology analogue matching are not proved by these summaries and remain separate audit items.

## Concentric discovery (§10, §18 step 8)

Research now automatically searches the displayed catalog when data/time/filters update. It tests ten fixed spacings (250–2500 km), up to six rings within 10,000 km, ±15% spacing bands, around the strongest 24 sources deeper than the configured trigger. Results require three occupied rings and open the existing inspector at the selected spacing; that inspector retains matching event evidence. This is bounded exploratory discovery, not an unrestricted all-event global search, independent null-controlled significance, directional propagation or a new forecast score. Those stronger claims remain unproved.

## Historical sequence analogues (§23)

The existing neural search encodes a source plus up to seven preceding neighbors within ten days/3500 km, using relative magnitude, depth, time and pair distances; pretrained local text embeddings rank up to 160 eligible completed historical sources. Future outcomes are excluded from encoding and attached after ranking. This is genuine sequence-graph retrieval, but it does not yet explicitly encode configured route topology, tectonic boundary type, swarm dynamics or midpoint structure requested by §23. Those fields remain implementation gaps; the simpler source-magnitude/depth search must not be presented as their replacement. Both paths now share earthquake/provider/deletion/cutoff eligibility, including follow-up counting.

Sequence encoding follow-up: relative-sequence-graph-2 now adds support near geodesic midpoints of graph-node pairs 500–3500 km apart (200 km neighborhoods, source-time observations only) and local 400 km activity counts in the preceding two five-day halves, with mean depth change. Query and match graph text are inspectable in Research. Versioned embedding keys separate earlier vectors. These are descriptive features, not proof of silence or a fitted swarm; explicit configured-route topology and boundary type remain unimplemented.

## Classified tectonic context (2026-09-28)

Graph v4 adds each graph node's nearest PB2002 classified step and spherical distance, using all 5,824 source steps and seven published classes (CCB, CTF, CRB, OSR, OTF, OCB, SUB). Original START/FINAL coordinates define bounded minor great-circle arcs; endpoint caps and dateline crossings are handled. This uses source digitization-step endpoints, not an inferred physical association or the display GeoJSON's densified vertices. The source is pinned to fraxen/tectonicplates revision b53c3b7d82afd764650ebdc4565b9666795b9d83, SHA-256 528fdeb1d57eb3d4c6e730951eabc6fd7da9dbc5fc7038b9f19100c52b986c9a. Bird (2003), doi:10.1029/2001GC000252; conversion Hugo Ahlenius / Nordpil, Open Data Commons Attribution 1.0. Setup downloads and verifies the original GeoJSON; runtime verifies its checksum. Missing data is explicitly unavailable. No classes are inferred from the unclassified overview map or experimental routes.

Feature evidence retains source step IDs, endpoint coordinates, classes, distances and dataset citation/checksum. PB2002 is a static modern reference applied retrospectively, not contemporaneous historical forecast evidence or a causative-fault assignment. The local nomic embedding run compared 160 candidates and returned 12 results with graph v4; artifacts/neural-boundary-check.json retains the response. All 197 tests passed, including dateline distance, endpoint caps, opposite-hemisphere endpoint selection, invalid class rejection and separation from experimental route geometry. This closes explicit geological class encoding in the sequence fingerprint, not training or validation of a seismic graph neural network.
